# Genshin Exploration Tracker

A web app for tracking your exploration progress across all regions and oculi in Genshin Impact.

## Features

- **Region tracking** - Mark each region as Complete, Working on it, or Not started
- **Oculi tracking** - Track collection progress for all oculi types across patches
- **Progress charts** - Pie chart breakdowns of your exploration and collection status
- **Notes** - Add personal notes per region or oculus
- **YouTube embeds** - Link walkthrough videos and watch them inline
- **Search** - Filter regions and oculi across all nations
- **Dark mode** - Toggleable with system preference detection
- **Local storage** - All progress is saved in your browser

## Regions

Covers all 8 nations: Mondstadt, Liyue, Inazuma, Sumeru, Fontaine, Natlan, Nod Krai, and Snezhnaya/Khaenri'ah (placeholder).

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Recharts

## Getting Started

```bash
npm install
npm run dev
```

Opens at [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
